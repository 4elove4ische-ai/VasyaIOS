# Вася — iPhone prototype

Бесплатный исходный проект для Xcode (SwiftUI). Для сборки нужен Mac с Xcode или доступ к macOS; Windows сама по себе не собирает iOS-приложения. Бесплатный Apple ID подходит для локального тестирования через Xcode с ограничениями.

## Что реализовано
- Экран с кнопкой записи речи.
- Распознавание русской речи средствами Apple Speech.
- Голосовое озвучивание ответов.
- Разбор двух типов команд: «открой ...» и «найди ... в Яндекс Навигаторе».
- Открытие известных приложений через URL-схемы (если поддерживаются и установлены); без попыток управления их закрытыми интерфейсами.

## Установка
1. На Mac с Xcode создайте iOS App (SwiftUI, Swift), назовите Vasya.
2. Замените содержимое VasyaApp.swift и ContentView.swift файлами из этого архива.
3. В Info добавьте NSMicrophoneUsageDescription и NSSpeechRecognitionUsageDescription с объяснениями.
4. В Signing & Capabilities выберите свою команду (Personal Team), подключите iPhone и нажмите Run.

## Ограничения
Это стартовый прототип, не готовый мотопомощник. Работа Cardo, фоновая активация, управление звонками/сообщениями и реальная интеграция с Яндекс Музыкой не реализованы. Запуск сторонних приложений зависит от их URL-схем и политики iOS. Никаких платных API или аккаунтов в проекте нет.

## Бесплатная сборка IPA через GitHub Actions (экспериментальный путь)
1. Создайте бесплатный репозиторий GitHub и загрузите содержимое папки VasyaIOS **в корень репозитория**, включая скрытую папку `.github`.
2. Откройте вкладку Actions → Build unsigned Vasya IPA → Run workflow.
3. После успешной сборки скачайте артефакт `Vasya-unsigned-ipa`, распакуйте ZIP и получите `Vasya-unsigned.ipa`.
4. Передайте IPA в Sideloadly для подписи своим Apple ID и установки на iPhone через USB.

Важно: это **не проверенная в CI сборка**; возможны ошибки компиляции и ограничения бесплатных минут GitHub Actions на macOS. IPA без подписи нельзя устанавливать напрямую. Не публикуйте ключи и пароли Apple в GitHub. Проект пока не поддерживает полноценный ИИ или фоновую активацию.
